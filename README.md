# Chromatic · 梯度色生成器

一个面向设计系统的 13 阶梯度色生成器。支持品牌色、辅助色与中性色的浅色/暗色色板，并提供单色复制、CSS 变量复制和 JSON 导出。

## 功能

- 品牌色 / 辅助色：以 `color-9` 为基准，使用 HSB 算法向两侧生成色阶
- 中性色：以 `color-13` 为基准，使用 HSL 算法生成浅色和暗色色板
- 暗色品牌色：以中性色基准叠加不同透明度的浅色色板
- 输入 HEX 色值、拖动 HSB/HSL 通道或使用原生颜色选择器实时调整
- 每个色块同步展示对应的 HSB 或 HSL 通道值
- 品牌色和中性色同时展示，每套 13 阶色板保持单行排列
- 一键复制 CSS 变量、下载完整 JSON tokens
- 浅色响应式界面与完整仪表盘应用预览

默认品牌色为 `#FF6000`，默认中性色为 `#0F131A`。
